Implementation Notes

Rolling source of truth for what is implemented and what still needs device verification.

Implemented

  • The Flutter app downloads the optional Gemma 2 MediaPipe task model directly from the public Hugging Face bucket, then initializes flutter_gemma.
  • LlmService clears chat history per request, uses conservative generation settings, and removes malformed control-token/prompt-echo output.
  • The model-release upload workflow was removed because this 2.71 GB asset exceeds GitHub Releases' 2 GiB per-file limit.

Open verification

  • Use a real compatible task model on an Android device with sufficient free storage and test several independent prompts for repetition.
  • Run a release APK build.
