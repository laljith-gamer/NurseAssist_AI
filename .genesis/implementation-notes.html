Implementation Notes

Rolling source of truth for what is implemented and what still needs device verification.

Implemented

  • The Flutter app downloads an optional model from a GitHub Release, then initializes flutter_gemma with the MediaPipe task backend.
  • LlmService clears chat history per request, uses conservative generation settings, and removes malformed control-token/prompt-echo output.
  • The release workflow downloads a source model and uploads it to a tagged GitHub Release.

Open verification

  • Use a real compatible task model on an Android device and test several independent prompts for repetition.
  • Run a release APK build after the model release succeeds.
