NurseAssist_AI

Product boundary

NurseAssist supports nursing workflows. It may assist with language, but must not invent clinical facts, measurements, medications, or patient records. Structured actions remain deterministic; the local LLM is optional.

Definition of Done

  • A clean Android install can download exactly one compatible .task asset from the configured GitHub Release.
  • The model initializes and answers multiple unrelated prompts without repeating earlier prompts, instructions, or prior conversation.
  • Model failures leave the deterministic clinical-command experience usable.
  • flutter build apk --release succeeds from frontend.
  • Release tag, model filename, and download URL are verified as one contract.

Current status

Not done: the model publishing workflow needs a valid licensed source model before device verification and release APK sign-off.
