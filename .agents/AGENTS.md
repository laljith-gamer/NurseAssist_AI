# Agent Rules

## Genesis Workflow
Always read the `.genesis` directory (specifically `.genesis/KICKOFF.md`, `.genesis/PLAN.md`, and `.genesis/checkpoints/CURRENT.md`) before taking any action in this repository to understand the current project state, architecture, and active milestones.

Whatever action you take or code you write, you MUST always update the `.genesis/PLAN.md` and `.genesis/checkpoints/CURRENT.md` files to reflect your changes before concluding your work.
