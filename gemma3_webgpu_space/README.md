# Gemma 3 1B IT - WebGPU Inference

This space runs the `gemma3-1b-it-int4-web.task` quantized model fully in your browser via WebGPU using Google's [MediaPipe LLM Inference API](https://developers.google.com/mediapipe/solutions/genai/llm_inference/web_js).

Since inference runs purely on the client-side, there are **0 GPU costs** and no server-side queues!

## Resources
* Model: [litert-community/Gemma3-1B-IT](https://huggingface.co/litert-community/Gemma3-1B-IT)
* Engine: `@mediapipe/tasks-genai`
